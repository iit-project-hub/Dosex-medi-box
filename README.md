# DoseX Project Showcase

A responsive animated presentation website for the DoseX Smart Medicine Dispenser Robot.

## Files
- `index.html` — website structure and content
- `style.css` — responsive styling and animations
- `script.js` — scroll animations, navigation, and progress bar

## Run locally
Open `index.html` in a browser.

## Deploy on GitHub Pages
1. Create a GitHub repository.
2. Upload all three files to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose `main` and `/root`, then save.
