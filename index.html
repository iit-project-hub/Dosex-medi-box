01 / PROJECT OVERVIEW

One robot.
Many layers of care.

✦

Designed around people

DoseX combines scheduled medication management, user authentication, automatic medicine selection, a front collection compartment, robot mobility, obstacle sensing, and a docking concept in one compact platform.

A concept focused on accessibility, safety, and dependable medication routines.

⌁

Intelligent by design

The controller maps each scheduled medicine to its assigned internal tray and activates the relevant dispensing actuator only when the request is valid.

◈

Safety first

Invalid authentication and requests outside the permitted schedule must never release medicine.

03 / SYSTEM LOGIC

From schedule
to safe delivery.

01

Schedule stored

The DoseX application/controller stores the medication timetable and tray assignments.

02

User authenticates

The user provides authentication at the permitted medication time.

03

Controller validates

The system checks timing, identity, and the assigned medicine tray.

04

Dose presented

If valid, the actuator releases the dose to the front collection compartment.
